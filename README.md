# วิธี Explicit สำหรับสมการความร้อน

ตัวจำลองวิธีผลต่างสืบเนื่องแบบ explicit (explicit finite difference method) สำหรับสมการเชิงอนุพันธ์ย่อยแบบพาราโบลิก

$$u_t = c^2 u_{xx}, \qquad 0 \le x \le L,\ t \ge 0$$

อ้างอิงจาก E. Kreyszig, *Advanced Engineering Mathematics* หัวข้อ 21.6 (Methods for Parabolic PDEs) และหัวข้อ 12.6 (คำตอบแม่นตรงด้วยอนุกรมฟูเรียร์)

## สูตรที่ใช้

แทนอนุพันธ์ด้วยผลต่างบนตาราง $x_i = ih,\ t_j = jk$ ได้สูตร (5)

$$u_{i,j+1} = (1-2r)\,u_{ij} + r\,(u_{i+1,j} + u_{i-1,j}), \qquad r = \frac{c^2 k}{h^2}$$

วิธีนี้ลู่เข้าและเสถียรเมื่อ $r \le \tfrac12$ (เงื่อนไข (6))

## ความสามารถของตัวจำลอง

- เลือกโจทย์จากหนังสือ (Example 1, แบบฝึกหัด 21.6 ข้อ 5, 6, 7, 9, 10) หรือกำหนดเอง
- กำหนดเงื่อนไขเริ่มต้น $f(x)$ และเงื่อนไขขอบได้ทั้งแบบกำหนดอุณหภูมิ ($u = g(t)$) และแบบกำหนดอัตราการไหล ($\partial u/\partial x = g(t)$)
- ตารางคำนวณทีละช่อง แสดงว่าค่าแต่ละช่องมาจากช่องไหนของแถวก่อนหน้า พร้อมสมการที่แทนค่าแล้ว
- เทียบกับคำตอบแม่นตรงจากอนุกรมฟูเรียร์ แสดงค่าคลาดเคลื่อนและเปอร์เซ็นต์
- กราฟอุณหภูมิ และ heat map ในตารางที่กำหนดช่วงและสีได้
- เล่นอัตโนมัติ เลือกความเร็วได้ 0.5× ถึง 32×
